# Контакты бригады: звонки и WhatsApp

Добавлено 18 октября 2026 года. В кабинете бригады есть отдельный раздел «Контакты для клиентов»: номер для звонков и номер WhatsApp. Можно указать оба, только один канал либо включить «Этот же номер использовать в WhatsApp». Требуется хотя бы один корректный номер. Указанные номера явно объявлены публичными до публикации профиля.

Номера приводятся к `+7XXXXXXXXXX` на клиенте и сервере. Разрешены привычные пробелы, скобки и дефисы, начало `8` или `7` для одиннадцатизначного номера и десятизначная местная запись. Другие коды стран, ссылки, дополнительные команды, буквы, слишком короткие/длинные значения отклоняются. Это проверка формата, не подтверждение владения номером или регистрации в WhatsApp.

Ссылка звонка — `tel:+7...`, ссылка чата — `https://wa.me/7...` без знака плюса и разделителей. Используется официальный формат Click to Chat: https://faq.whatsapp.com/5913398998672934 . Кнопка чата открывается отдельно с `noopener noreferrer`. Сайт не отправляет сообщений автоматически, не читает переписку и не использует WhatsApp API или его ключи. Для реального чата необходим действующий WhatsApp-аккаунт на указанном номере.

Миграция `0003_cultured_the_professor.sql` добавляет только поле `profiles.whatsapp` с постоянным пустым значением по умолчанию. Она не изменяет старые номера и не предполагает, что они подключены к WhatsApp. У старых профилей сохраняется кнопка звонка, чат появляется только после явного указания номера. Старый клиент, не передающий поле WhatsApp, не стирает уже сохранённый номер; явная пустая строка удаляет его. Демонстрационные профили не содержат активных контактных ссылок.

Сохранены серверная идентификация владельца, проверка Origin, ограничения тела/частоты запросов, строгая схема, параметризованный SQL и атомарная проверка своих фотографий. Пользовательские URL в контакты не принимаются; адреса кнопок создаются только из проверенных цифр. Эти изменения не относятся к контактам клиентов внутри приватной CRM.

Проверки:

- `node tests/contact-numbers.mjs` — нормализация, безопасные ссылки и отклонение некорректного ввода.
- `node tests/contact-numbers.mjs http://127.0.0.1:5174` — 17 сценариев API/страниц, включая независимые номера, один номер на оба канала, только WhatsApp, удаление чата, защиту от подмены и совместимость старого профиля. Для последнего сценария локальная фикстура `contact-legacy-fixture` создаётся до применения новой миграции.
- Браузер: создание, редактирование и перезагрузка профиля; переключатель общего номера; очистка телефона при включённом переключателе; оба типа кнопок; отсутствие записи при некорректном вводе; ширины 1440, 1024, 768, 390 и 320 px. Без ошибок страницы и горизонтального переполнения.
- Повторные проверки: все 90 городов и общие специализации, 28 проверок CRM, 33 проверки обработки/хранения изображений, TypeScript и производственная сборка.

Все тестовые записи — только в отдельной локальной D1/R2, исключённой из публикации. Клики WhatsApp перехватываются локально до обращения к сервису, звонки отменяются до запуска телефонного приложения: тест не связывается с владельцами номеров и не проверяет доставку сообщений. Проверки с прямыми фикстурными записями через локальный Wrangler нужно запускать последовательно, чтобы несколько процессов не блокировали один SQLite-файл.
